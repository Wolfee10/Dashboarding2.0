# SignalBoard AI Dashboard

A basic React and TypeScript starting point for building KPI dashboards.

## Run The App

```bash
npm install
npm run dev
```

## What Is Included

- Vite React application scaffold
- Minimal blank dashboard workspace
- ECharts dependency installed for charts when the KPI structure is ready

## Next Step

The KPI fields, chart choices, and layout can be added once the KPI list and data shape are defined.
